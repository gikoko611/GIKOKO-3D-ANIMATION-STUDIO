## Important compatibility note

These files are copied skill instructions, not installed engines. Their scripts, templates, assets, models, dependencies and required tool integrations are not automatically copied. Some skills describe recent Blender APIs or desktop GPU/browser workflows that are not suitable for direct execution on the Redmi 9A. Check each skill's prerequisites before invoking it. The source repositories may change; this snapshot reflects the content fetched when this import was made.
