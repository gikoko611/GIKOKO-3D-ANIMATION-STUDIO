# Upstream Skill and Tool Catalog

This is a curated reading list for optional specialist workflows. G.I Animation Director consolidates production concepts into its own guidance; it does not vendor third-party source code, models, demos or assets. Check each upstream repository's current license and dependencies before copying or redistributing anything.

## 3D artist / animator
- https://github.com/matinsizen/ai-3d-animator-skill — Three.js + Blender pipeline, style bibles, rigged example models and sound design. The upstream README describes MIT licensing; verify the license at the exact revision used.
- https://github.com/kajisho5/blender-skill — headless Blender asset pipeline and GLB inspection/export.
- https://github.com/Olioli4/blender2three-skills — Blender-to-Three.js export and web-rendering workflow.

## Stickman and cartoon shorts
- https://github.com/Shashank33549/stickman-animation — procedural stickman rigging, IK, camera systems and cartoon 3D shorts.
- https://github.com/ittahad/stickman-animation — stickman animation library and skill packaging; check Pillow and FFmpeg requirements.
- https://github.com/cafermutluozkan/stick-motion — browser-based jointed stick-figure animation.

## Motion graphics and code-driven video
- https://github.com/VisualxIntelligence/motion-tools-and-skills — motion-design skills, Three.js, GSAP, HyperFrames, Remotion, Blender and ComfyUI references.
- https://github.com/Hmzbo/animation-skills — Manim, Motion Canvas, Three.js and GPU shader skill collection.
- https://github.com/magnus919/agent-skills — focused Three.js/WebGL scene skill.

## Safe reuse procedure
1. Read the upstream README and license at the exact commit or tag.
2. Inspect install scripts and dependencies before running them.
3. Prefer implementing compatible local workflows rather than blindly copying code.
4. Preserve attribution and license notices for imported code, models, fonts, textures and sound.
5. Do not assume upstream projects are ARMv7-compatible or free of external API costs.
